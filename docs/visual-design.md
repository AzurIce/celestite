# Celestite 视觉与交互规范

本规范定义已确认的 UI/UX 设计，生产组件按此统一主题、布局与操作归属。界面迁移沿用现有文件、编辑会话与保存语义；具体能力范围和限制见 [Web 文档](../web/README.md)。

## 设计方向

工作区提供类似 Obsidian 的文件组织与多文档操作，书写区保留类似 Typora 的连续阅读感。精致感来自文字比例、对齐、留白和清楚的反馈；正文始终是视觉落点。

工作区参考 [Obsidian 的侧栏与标签组织](https://obsidian.md/help/workspace)，长文导航与专注体验参考 [Typora 大纲](https://support.typora.io/Outline/)及[聚焦与打字机模式](https://support.typora.io/Focus-and-Typewriter-Mode/)。设计采用适合 Celestite 现有能力的取舍。

品牌使用项目自己的 [Logo](../icons/64x64.png)。蓝色主要用于链接、键盘焦点与小面积状态指示，工作区使用中性石灰色，深色主题使用石墨色。正文标题、文件树与普通按钮不承担品牌着色；主要按钮使用中性文字色与纸面反色。

界面贴合窗口边缘，文档是连续画布。纸面不增加卡片外框、阴影、纹理或装饰性圆角；菜单、提示和对话框使用必要的边界与轻阴影。使用真实窗口环境，不绘制虚构的系统窗口按钮。

## 工作区层级

| 层级   | 内容                                       | 布局                                                                 |
| ------ | ------------------------------------------ | -------------------------------------------------------------------- |
| 工作区 | 当前 Vault、文件导航、新建、设置与连接管理 | 左侧导航；Vault 选择器位于顶部，设置位于底部                         |
| 文档   | 打开的标签、路径、显示模式与文档操作       | 轻量标签栏与单行文档栏；文件身份和操作不再分散到多条状态横栏         |
| 正文   | 标题、段落、链接、代码与其他文档内容       | 居中阅读列；正文标题保留在内容里，不额外制造一份可编辑标题           |
| 上下文 | 文档大纲、诊断、成员与相关状态详情         | 按需打开的面板或浮层；大纲放右侧，成员入口放文档栏，不单占一条协作栏 |

标签名称用于切换文档，路径用于说明位置，两者采用不同的视觉权重。激活文件与调整窗口后，当前标签保持可见；打开文档列表提供带完整路径和未保存状态的切换与关闭入口，窄屏由标题展开该列表。正文上方不再重复一个与标签同权重的文件名。正常保存与预览更新状态使用轻量反馈，异常就近显示可操作的说明。

### 布局尺寸

| 项目     | 规格                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 左侧导航 | 默认 248px，可调整宽度与收起；树行高 30px，层级缩进 16px               |
| 标签栏   | 40px；当前标签使用中性底色与正常文字，关闭按钮和未保存标记独立表达状态 |
| 文档栏   | 36px；左侧弱化路径，右侧放模式、上下文入口与更多操作                   |
| 状态栏   | 24px；正常状态低干扰，技术详情按需展开                                 |
| 右侧大纲 | 224px，默认收起；较窄窗口优先让出正文空间                              |
| 正文     | 文本列最大 660px；桌面外盒 764px，左右各 52px；较窄窗口各 42px         |
| 控件     | 常规高度 32px、紧凑高度 28px；圆角 6px                                 |
| 浮层     | 圆角 10px，细边框与轻阴影                                              |
| 图标     | 沿用 Lucide；常规 16px，线宽约 1.75                                    |
| 基础间距 | 4px 基准，常用 8、12、16、24、32px                                     |

文件树保留连续列表结构。当前项使用中性底色，键盘焦点与拖放落点清楚可见。侧栏保留一个易发现的新建笔记入口，输入标题即可创建 Markdown 笔记；通用新建文件仍使用完整文件名。空态提供创建与打开目录入口，并说明文件的存储位置。导入、刷新、折叠全部等低频动作进入更多菜单。

## 字体与正文排版

| 项目     | 规格                                                         |
| -------- | ------------------------------------------------------------ |
| 界面字体 | 系统无衬线字体；中文使用平台中文字体或 Noto Sans SC          |
| 界面正文 | 13px，行高 1.5                                               |
| 辅助文字 | 12px；通过颜色和位置表达次要层级，保持可读性                 |
| 阅读正文 | 17px，行高 1.85                                              |
| 一级标题 | 30px，字重 600，行高 1.45                                    |
| 二级标题 | 23px，字重 600，行高 1.45                                    |
| 三级标题 | 19px，字重 600，行高 1.45                                    |
| 四至六级 | 17px，字重 600，行高 1.45                                    |
| 段落间距 | 14px                                                         |
| 章节间距 | 标题前 36px，标题后 12px；文档开头不额外制造章节留白         |
| 代码字体 | SFMono-Regular / Consolas / Liberation Mono / Noto Sans Mono |
| 源码编辑 | 14px，行高 1.65；行号与语法标记保持源码语义                  |

中英文混排使用同一条稳定的阅读节奏，长标题自然换行，不使用海报式巨型标题。实时渲染支持的结构与预览、分栏预览使用相同正文排版；模式切换时不因视觉样式修改原始正文。当前实时渲染的结构覆盖范围以 Web 文档为准，不将预览支持等同于实时编辑支持。

链接保留下划线。行内代码采用轻微中性底色，代码块使用等宽字体和适度留白。引用以细中性边线、缩进和次要文字表达，重点不依赖大面积蓝色。表格、代码块、图片与组件保持文档结构，不变成独立装饰卡片。

## 中性主题

颜色集中维护在 [theme.css](../web/src/styles/theme.css)，编辑器、预览与浮层使用同一组语义变量。深浅主题共享布局、尺寸和操作位置。

| 语义       | 浅色      | 深色      | 用途                           |
| ---------- | --------- | --------- | ------------------------------ |
| 正文纸面   | `#FCFCFA` | `#212220` | 文档、主要内容与浮层           |
| 工作区框架 | `#F0F0ED` | `#1C1D1B` | 侧栏、标签框架与底栏           |
| 悬停底色   | `#E8E8E3` | `#2C2E29` | 普通操作悬停                   |
| 选中底色   | `#E2E3DD` | `#34362F` | 当前文件与普通选中项           |
| 正文文字   | `#292A2D` | `#DEDED9` | 正文、标题与主要操作           |
| 次要文字   | `#6B6E69` | `#A1A49D` | 路径、元信息与辅助文字         |
| 装饰分隔线 | `#E4E5DF` | `#30332C` | 面板边界与表格分隔             |
| 控件边界   | `#8B8D85` | `#74776E` | 需要明确形状的输入框与控件     |
| 强调与焦点 | `#58718C` | `#A8BDD0` | 链接、键盘焦点与小面积选中指示 |

普通文字、辅助文字和链接在实际背景上达到 4.5:1；控件边界、焦点和重要图形达到 3:1。浅色主题的辅助文字用于纸面或工作区框架，在悬停和选中底色上使用正文色；有轮廓的输入控件使用纸面底色。装饰分隔线只承担分组，不能成为唯一的控件识别方式。悬停、选中、禁用和叠加色按实际背景校验。

成功、警告和错误保留独立语义色，同时使用图标和说明文字；蓝色不替代这些状态。语法高亮保持克制，源码中的字符串、关键字和诊断仍可区分，正文模式中的标题与强调不继承源码高亮颜色。

## 交互与能力归位

下表规定能力在工作区中的归属。界面组合保留调用语义和失败处理，不把文档、保存或恢复状态再复制到视图层。

| 能力                                                   | 目标入口与呈现                                                         |
| ------------------------------------------------------ | ---------------------------------------------------------------------- |
| 切换 Vault、打开本机目录、连接远端、复制链接与移除连接 | 侧栏顶部 Vault 菜单与连接管理浮层；本地和远端身份可辨认                |
| 全局设置、主题、侧栏宽度、编辑默认值与项目覆盖提示     | 侧栏底部设置入口；设置保存失败与重试留在设置界面                       |
| 新建文件、文件夹、导入、刷新与折叠                     | 新建为主要入口，其余归侧栏更多菜单                                     |
| 文件多选、复制、剪切、粘贴、移动、重命名、删除与下载   | 文件树右键菜单、拖放和原有快捷键；保留键盘操作                         |
| 标签切换、关闭当前、其他、左右与全部，中键关闭         | 标签栏与标签右键菜单；关闭仍遵守原有保存与失败保留策略                 |
| 源码、实时渲染、分栏、预览                             | 文档栏中的一个模式菜单；四种模式并存                                   |
| 源码换行、分栏滚动同步                                 | 模式菜单或文档更多菜单中的适用项                                       |
| 文内查找替换、跳转行、悬浮提示、F12 与编辑器诊断       | 沿用编辑器内交互与现有快捷键                                           |
| Notist 文档符号                                        | 可收起的右侧大纲；结构能力以现有语言服务支持为界                       |
| 在线人数、当前文档成员、成员详情与只读身份             | 文档栏右侧的轻量成员入口；单人工作不占用一条协作横栏                   |
| 预览刷新、失败重试、资源目录授权与诊断定位             | 预览操作菜单和就近错误提示；授权仅在适用平台与连接出现                 |
| 保存、光标、语言、编码、换行符与 Vim 状态              | 状态栏保留关键状态，其余可展开；源码模式仍能直接确认光标与 Vim 状态    |
| 外部修改、保存冲突、恢复失败、断连与未确认输入         | 按错误作用范围显示持续、可操作的提示或恢复界面，保留现有动作与交互限制 |

显示模式继续使用所有文件与 Vault 共用的全局偏好，刷新后保留；文件不支持该模式时回退为源码；窄屏暂将分栏呈现为预览，菜单勾选实际视图，禁用分栏并说明窗口限制，加宽后恢复原偏好。实时渲染始终按阅读列换行，源码换行沿用用户设置。

聚焦模式收起文件导航与上下文面板，减少健康状态的干扰，保留易发现的退出入口。进入与退出聚焦、切换模式和打开面板应保留正文、选区、滚动位置与输入会话。

快速打开用于按文件名和路径片段查找并打开当前 Vault 的文件，支持空格组合片段；分批呈现结果时，鼠标与键盘都能访问剩余项，与编辑器的文内查找和文件树前缀键盘定位各有明确入口。它不承担全文检索、标签、关系图或历史版本功能；大纲能力以现有 Notist 语言服务支持为界。

独立预览保持阅读行为：正文单击不切换模式，大纲只定位阅读位置。分栏中点击正文仍可定位源码，诊断保持显式源码定位。正常预览状态合并到工作区底栏，刷新与依赖授权放文档菜单；失败时就近显示重试与适用的授权入口。阅读态底栏突出保存和字数，技术详情按需在文档菜单查看。

### 必须清楚表达的异常

- 未保存、正在保存、已保存和保存失败具有可辨认的文字状态；失败持续显示重试入口，不能只出现短暂提示。
- 只读身份与不能编辑的原因清楚可见；文件树和正文中的写入入口、快捷键与拖放均禁用，保留浏览、复制和下载。
- 连接移除提示区分本地保存与远端编辑发送确认，不承诺未执行的磁盘保存；同名库通过来源与权限区分。
- 外部修改、普通保存冲突与共享保存冲突保留各自的处理方式，不统一成含糊的同步图标。
- 远端断连后冻结当前 Vault 的文件树和编辑区，明确显示重连与恢复动作；不暗示离线编辑或后台自动补交。
- 未确认输入保留导出正文和明确丢弃后重连等现有动作；输入拒绝与恢复材料写入失败保留可操作说明。
- 预览与资源授权失败不遮盖已经可用的编辑内容；错误附带定位、重试或授权入口。

## 窄屏、键盘与可访问性

700px 及以下窗口使用单列文档，正文左右留白 22px，保留 17px 正文字号；一级标题为 27px、行高 1.5，二级标题为 22px。顶部提供明确的文件导航入口与返回路径；文件树使用独立导航层或抽屉，模式和文档操作进入菜单，避免横向堆叠桌面工具栏。

图标按钮提供可访问名称，常用动作显示快捷键提示。菜单支持方向键、Enter 和 Esc，关闭浮层后恢复原焦点；面板显隐不打断编辑器组合输入。文件树、标签与调整尺寸控件保留键盘语义，键盘焦点不依赖悬停才可见。

触摸操作目标至少 44px；紧凑桌面图标可保持较小视觉尺寸。普通过渡约 120ms，遵守 `prefers-reduced-motion`。验证覆盖浅色、深色、长中文标题、中英混排、窄屏、键盘导航与放大后的可读性。

## 实现与验证边界

主题、排版与公共控件集中维护；工作区只组合导航、编辑和上下文面板，不新增文档状态所有者。实际编辑继续经过同一套 core、CodeMirror 输入和会话边界。焦点交接由编辑器执行，工作区不直接聚焦 CodeMirror 内部 DOM；只有实际的文档激活才恢复编辑焦点，成员、保存和预览状态更新不抢焦点。

验证同时覆盖外观与真实编辑：浅深主题、窄屏、键盘与焦点，以及保存、撤销、中文输入、协作、权限、断连恢复和关闭策略。预览的丰富排版不替代对实时编辑结构和输入行为的验收。
