# Celestite 天青石：霜瓷视觉规范

Celestite 使用「霜瓷」作为统一视觉风格：明亮白面、清蓝强调、舒展的无衬线正文与柔和圆角。浅色主题「瓷白」与深色主题「夜瓷」共享布局、尺寸与交互语义。

沿用项目的 [天青石晶体图标](../icons/128x128@2x.png)。品牌图标保留晶体的渐变与切面，工作区以平整色面、细分隔线和留白组织内容。正文是主要视觉落点，侧栏与状态栏使用较暗一层的框架背景。

## 配色

颜色集中定义在 [theme.css](../web/src/styles/theme.css)，通过 [uno.config.ts](../web/uno.config.ts) 映射为语义工具类。编辑器、预览 Shadow DOM 与浮层继承同一套主题变量。

| 语义变量                    | 瓷白      | 夜瓷      | 用途                                 |
| --------------------------- | --------- | --------- | ------------------------------------ |
| `--color-surface`           | `#FFFFFF` | `#1C2535` | 正文、编辑区、浮层                   |
| `--color-background`        | `#F3F6FA` | `#161E2C` | 侧栏、状态栏、框架                   |
| `--color-muted`             | `#E9EEF6` | `#2A364D` | 悬停、当前标签、行内代码             |
| `--color-selected`          | `#E0E9F8` | `#2C3F5C` | 当前文件、文字选区、菜单高亮         |
| `--color-foreground`        | `#253145` | `#E5EBF7` | 正文、标题                           |
| `--color-secondary`         | `#55657B` | `#A6B6CE` | 元信息、路径、行号与辅助文字         |
| `--color-border`            | `#DDE5EF` | `#34435C` | 面板分隔线与装饰边界                 |
| `--color-control-border`    | `#71869F` | `#667F9F` | 输入框与常规按钮边界                 |
| `--color-accent`            | `#3D64AC` | `#A7C4FB` | 链接、主要操作、未保存标记、Vim 光标 |
| `--color-accent-hover`      | `#31538F` | `#C4D7FC` | 主要操作悬停                         |
| `--color-accent-foreground` | `#FFFFFF` | `#172842` | 强调色背景上的文字                   |
| `--color-focus`             | `#587DB3` | `#829FCB` | 键盘焦点与输入框聚焦                 |
| `--color-success`           | `#507966` | `#9FC4AD` | 明确的成功反馈                       |
| `--color-warning`           | `#8B6935` | `#D2B889` | 冲突与待处理状态                     |
| `--color-danger`            | `#A44E50` | `#DFA0A0` | 错误、失败与破坏性操作               |

蓝色用于有意义的交互与状态。正文标题保持普通文字色；链接保留下划线，选中项保持正常文字色。日常的「已保存」信息使用次要文字和图标，错误与冲突同时使用说明文字、图标与独立状态色。

普通文字、链接和状态文字与所在背景的对比度应达到 4.5:1；焦点与控件边界应达到 3:1。装饰分隔线保持轻微，控件使用独立的边框色。新增透明色叠加或禁用态时，按实际背景核对可读性。

## 字体、间距与形态

| 项目                | 规范                                                               |
| ------------------- | ------------------------------------------------------------------ |
| 界面与正文          | Inter / 平台系统无衬线字体，中文回退到 Noto Sans SC 或平台中文字体 |
| 代码字体            | SFMono-Regular / Consolas / Liberation Mono / Noto Sans Mono       |
| 界面字号            | 14px；工具栏、路径与状态栏 12px                                    |
| 阅读正文            | 16px，行高 1.9                                                     |
| 代码编辑            | 14px，行高 1.7                                                     |
| 文档标题            | 一级 28px、二级 22px、三级 18px；字重 500，行高 1.4                |
| 阅读宽度            | 含左右留白最大 728px，桌面正文可用宽度约 648px                     |
| 正文留白            | 桌面左右 40px，中等视口 28px，窄屏 16px                            |
| 段落与章节          | 段落上下 14px，章节前 28px                                         |
| 基础间距            | 4px 基准，常用 8、12、16、24、32px                                 |
| 控件 / 浮层圆角     | 8px / 12px                                                         |
| 常规 / 紧凑控件高度 | 32px / 28px                                                        |
| 顶部栏 / 状态栏     | 48px / 32px                                                        |
| 常规图标            | Lucide，16px，线宽 1.75                                            |
| 动效                | 颜色反馈约 120ms，遵守 `prefers-reduced-motion`                    |

通过比例、字重、底色差与留白形成层级。工作区贴合窗口边缘，阅读区保持连续；阴影仅用于菜单、提示和弹窗等浮层。深浅主题切换保持字宽、尺寸和操作位置一致。

## 工作区与交互

- **文件树**：使用框架背景，选中项为浅蓝填色，普通悬停使用中性浅底。键盘焦点用清晰轮廓，拖拽落点突出实际目标的整棵子树。
- **标签栏**：当前标签使用浅底和正常文字。关闭按钮与未保存点各自表达状态，工具栏保持轻量。
- **阅读区**：普通标题与正文使用中性文字色；引用以 2px 蓝色左边线和留白区分。链接保留下划线，表格和代码块保持可横向滚动。
- **编辑区**：行号和注释使用次要文字色；当前行叠加约 5% 的强调色。独立绘制选区背景，保留原有语法高亮文字颜色。
- **状态栏**：与侧栏同底色，使用细线分隔，正常信息使用次要文字。Vim 模式名使用小尺寸等宽文字。
- **按钮与菜单**：主要操作使用清蓝填色，其余操作使用轮廓或文字样式。选中按钮和菜单高亮使用统一选中色。
- **输入框**：使用清晰的控件边框，焦点以 2px 轮廓表达；错误附带可独立阅读的说明文字。
- **浮层**：使用正文底色、细边框、12px 圆角与轻阴影；遮罩以蓝灰中性色压暗背景。
- **Vim 光标**：NORMAL / VISUAL 使用清蓝块与反色字，失焦为空心轮廓，INSERT 使用竖线，REPLACE 保留底部条形。块内文字保持清晰，不继承原词的语法颜色。

## 语法高亮

语法颜色与主题变量一起维护，普通变量保持正文色，标点与注释使用次要文字色，标题与链接使用强调色。

| 语义        | 瓷白      | 夜瓷      |
| ----------- | --------- | --------- |
| 关键字      | `#725FA1` | `#C2B2E3` |
| 字符串      | `#4B746C` | `#A8CDC0` |
| 数字 / 常量 | `#8C6543` | `#D4B790` |
| 类型 / 函数 | `#3D64AC` | `#A7C4FB` |
